Post-processing of Abaqus results with the A_ scripts

Section export, image export and pushover curves — one module of the seismic analysis workflow

Scripts: Abaqus-scripts-for-output-processing / 3_export_and_image_export · Abaqus/CAE or Viewer 2021 (Python 2.7) · 10 November 2026

Open separately: SVG · PNG · PDF · editable: Visio, draw.io

Goes in

ODB files from the Abaqus analyses (one per job, Standard or Explicit), with the cross-sections defined as node and element SETs named TYPE&LABEL&INDEX&ANGLE; for 2a one ODB opened in Abaqus/Viewer.

Happens

1 displacements, rotations and forces of every section and frame; 2a pictures defined once, interactively; 2b every picture printed for every job and frame, curves drawn.

Comes out

Section histories (Ux, Uy, Uz, fix, fiy, fiz, Fx, Fy, Fz, Mx, My, Mz vs time) per SET and job; PNG images per job, variable, view and frame; pushover curves (PNG + CSV) with the image frames marked.

Section types (SET names)

TYPEgeometryaxesforces
V_PIER, V_SPECvolume (solid elements)pieryes
S_PIERshell (line of nodes)pieryes
V_SPANDRELvolumespandrelyes
S_SPANDRELshellspandrelyes
S_DRIFTpoint (nodal average)global axesno
SRIFTvolumepierno

Name: TYPE&LABEL&INDEX&ANGLE, e.g. V_PIER&RU&2&0. ANGLE turns the section axes about global Z; INDEX only numbers the section.

Using the module in another folder

Copy everything whose name starts with A_: A_1_Export_Auto.py, A_2_Image_export_Auto.py, A_2_Image_save_view.py and the folder A_IMPORT_additional_functions. Optionally the two *_settings.json files, to keep the saved settings (views, limits, curves). Order: 1 → 2a → 2b; 1 and 2b run unattended over all ODB files of the folder.
